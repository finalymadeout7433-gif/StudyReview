# 像素学习工坊

版本：2.2.0-defense.20261108.pixel4

## 本轮改动

- 学习助手新增原创像素书桌、三张快捷提问卡、像素图标和有按压反馈的工具按钮。对话历史、设置、输入框、发送、截图/图片工具与修改预览统一为纸张与绿叶配色。业务 API、发送确认和隐私流程不变。
- 窄窗口历史栏新增“返回对话”，新对话和关闭助手时重置历史展开状态，避免下次打开遮住输入区。320–1440 宽度检查按钮均可见、输入可保留、展开/还原和重复关闭正常。
- 左下角按页面显示八幅独立 SVG 小景：晨光温室、书房暖窗、园艺工作台、暮色水井、海岸帆船、星图露台、种子档案柜、灯下茶桌。它们沿用页面色板，但没有复用页面主图；无需网络或额外图片依赖。小屏沿用隐藏装饰图规则。
- 主窗口移除 Windows 标准标题栏/边框，使用同色原生细工具条和缩放边缘。保留拖动、边缘/角落缩放、最小化、最大化/还原、关闭以及未保存内容提示。浏览器没有新增 JS 权限桥；原有 WebView2 源校验/资源与弹窗限制保留。若自定义框初始化异常，则回退系统窗口框。

## 验收

- 422 项集成测试通过（1 项原有跳过）、88 项桌面测试通过、7 项 JavaScript 测试通过；系统检查与迁移遗漏检查通过。
- 源码与冻结程序均通过 18 组浏览器验收，包含八页/多宽度、八幅不重复侧栏图、助手快捷提问/设置返回/输入保留/展开还原/重复开关/历史返回/截图提示，以及专注角色与计时、导航前进后退、减少动态、灯塔与离屏暂停。
- 冻结程序实际原生操作通过：标题拖动、右边缩放、右下角缩放、最大化、最大化后拖动还原、最小化后恢复、关闭取消、Alt+F4 提示、确认关闭。最大化尊重任务栏工作区。
- 未验证多显示器/跨 DPI 切换及标题栏双击手势。没有实际调用 DeepSeek，AI 后端流程由隔离测试覆盖。
- 冻结包 74 个模板和静态资源与源码逐字节一致，未包含私人运行文件。相关凭据为 atelier-validation.json、atelier-evidence/checks.json、frozen-atelier-evidence/checks.json、atelier-package-audit.json 和 atelier-native-qa.json。
