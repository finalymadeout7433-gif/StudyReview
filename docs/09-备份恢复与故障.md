# 备份、恢复与故障

## 私有备份

SQL（完整表/触发器）、private/media与缩略图、django-secret.key、runtime引用及必要本机配置要同一时点保存；停止写入、记版本/时间/数量/哈希。旧文档的历史行数不代表当前数据量。DPAPI密文只对本人当前机器/用户有用，不分享给队友。

本人可用mysqldump --single-transaction --no-tablespaces --triggers --result-file='自己的私有路径' study_review_dev，选择本机host/port/user，用交互口令提示，不写密码进命令行。备份不入GitHub/issue/群聊。只复制SQL会丢图片，只复制当前图片会漏历史。

## 恢复与回退

先在新空隔离副本恢复，核对行、约束、触发器、图像清单/哈希、日期和页面，再本人决定切换；不向正在使用的库直接导入。开发/维护profile要求精确私有计划/白名单与显式schema授权。

普通运行用应用身份。回退保存旧程序与数据、先正常关闭当前窗口再换代码；不逆迁移删V2表，旧程序不显示新记录不等于数据不存在。

| 现象 | 核对及处理 |
| --- | --- |
| MySQL连不上 | 本机服务、host/port/账户/权限；不重装覆盖数据 |
| 初始化库已存在 | 确认旧安装/实例/端口；即使空库也不绕过 |
| 初始化中途失败 | 保留现场/计划，检查CREATE/GRANT/DDL；不自动删库 |
| 安全JSON错误 | 语法、字段、程序外路径；本机编辑，不展示口令 |
| WebView2/.NET缺 | 官方组件补齐，不用未知脚本 |
| 已有实例 | 保存旧表单正常关窗，不停共享MySQL |
| 无CSS | 完整解压_internal；源码collectstatic |
| 404/未登录 | 自己的账号、对象/归档范围，不取消权限来修复 |
| 草稿冲突 | 重新读取/生成，不强制覆盖新内容 |
| AI未连接 | 无Key/预算/确认；基础功能继续 |
| AI uncertain | 核对账单，不自动重试/增预算绕过 |
| 历史图打不开 | SQL/media时点/权限/哈希；不替旧历史关联当前图 |
| FSRS损坏/版本错 | 保留数据、明确修复，不清空 |

诊断EXE --diagnose配全新--diagnose-output；本人选配置后可--diagnose-database只读检查。未配置返回3，不建用户或业务表。报告无凭据值；排错只分享版本、步骤、类别与脱敏报告，不分享private/SQL/缓存。误传秘密先撤销再清理历史。
