# 章节复习与课程学习概况

这一轮把已有关系变成可直接操作的学习路径，没有为了表数量增加新表。当前22张业务表、9张框架表、44条外键；0013迁移之后为24个触发器。

## 从目录找到需要复习的内容

课程→章→节→知识点→错题是查询链路。一个错题可以关联多个知识点；章节错题数对题目ID去重，父章合并本章及其子节，因此同题关联两个知识点仍计一题。章节“关联错题”包含归档内容；“待复习”只包括活跃课程中未归档且到期的错题。未归类知识点继续保留。

错题页支持课程、章节/小节、知识点、关键词和全部/待复习/已安排切换。三个页签的数量基于同一筛选范围。切换课程时，旧课程的章节/知识点被清除并明确提示；外部账号的对象ID不能借筛选访问。待复习题可直接进入作答→查看答案→自评→保存流程，保存后更新下一次复习日。

## 课程学习概况的统计口径

统计页先给出课程概况，再展示趋势图；与页面的课程和起止日期筛选保持一致。

| 项目 | 口径 |
| --- | --- |
| 目录与知识点 | 当前未归档课程的章/节节点数、知识点数；不是历史区间计数 |
| 任务进度 | 当前课程的已完成/总任务数；不把专注结束当作任务完成 |
| 当前待复习 | 当前未归档且到期错题数；不把过去日期范围当成过去的待复习快照 |
| 区间复习 | 日期区间内真实复习记录，遵循全部/个人/示例来源筛选；沿用统计页未归档题目范围 |
| 区间专注 | 有效区间与所选上海自然日范围相交的秒数；暂停、休息不计，倒计时不超过目标时长；与复习来源无关 |

自由专注未绑定课程，不进入课程行；归档课程也不显示在这张概况中。全局专注历史可用于追溯。专注时长和复习次数不能等同于掌握度。

课程、任务、错题、复习及专注分别批量聚合，避免一个大JOIN将多对多内容乘法放大。非空课程概况查询在隔离测试中为6次（含专注区间预取），不逐课程增加查询。实际小样本EXPLAIN检查了章节和专注索引访问，不能据此声称完成大数据压测。

## 约束、兼容与回退

课程owner原先缺少数据库层的不可变保护，直接SQL可以转移课程并间接改变子记录归属。0013_course_owner_guard新增一个MySQL触发器：拒绝更改owner_id，保留重命名、归档等合法更新。不修改表字段、现有学习行或登录凭据。

隔离库实际撤回0013并重新应用，前后业务和认证表内容指纹一致；8类关联异常查询均为0。非法owner更新测试在修复前失败、修复后通过。普通业务账号不能绕过该触发器；具有DDL权限的管理员仍能移除保护，不声称对任何管理员操作不可篡改。

专注并发服务通过用户行锁串行化写入；有效区间重叠防护属于应用服务逻辑，不是数据库的排斥约束。迁移回退仅移除本轮触发器，会重新放开此限制，通常保留新保护并回退界面即可。
