# 清爽窗口与滚动

版本：2.2.0-defense.20261108.pixel5

## 改动

- 隐藏页面最外层的滚动条和预留轨道，不设置 overflow:hidden，不拦截 wheel、触摸或键盘事件。页面仍由浏览器正常滚动。
- 助手、编辑器和表格等内部滚动区不受影响。Windows 高对比度模式下恢复原生滚动条，保留系统可访问性提示。
- 顶部不再显示标题文字或独立底色，原生拖动区与当前页面背景色一致。右上角保留有提示文字、可键盘聚焦的最小化、最大化/还原和关闭按钮。
- 缩放区域不再绘制有色边框，边缘与角落仍可拖动缩放。最大化时隐藏缩放边缘并遵守任务栏工作区。
- 颜色由原生 WebView2 完成导航事件和静态页面色板选择，不读取网页脚本，不增加 JS 权限桥，也不修改来源、资源、下载或弹窗保护。

## 数据与回退

测试仅使用既有隔离合成数据，未读取或改写正式学习记录、数据库结构或模型密钥。旧 candidate-atelier 完整保留。原入口备份在任务目录 before-borderless-v5/pixel4-before.lnk，源码修改前也已备份。

只有最终验证通过后才将同一桌面“拾习-像素学习版”指向 candidate-borderless，保留原数据参数和其他快捷方式。同步 GitHub 时另行核验公开文件与远端状态，不包含本地程序包、备份或用户数据。

## 验证记录

任务目录中 borderless-validation.json、borderless-evidence/checks.json、frozen-borderless-evidence/checks.json、borderless-package-audit.json 和 borderless-native-qa.json 分别记录核心回归、源码页面、打包页面、包一致性与原生窗口实测。桌面入口变更成功时记录 borderless-desktop-update.json。

实体多显示器、动态 DPI 切换和实体触控板手势不属于本次自动化覆盖；连续小幅滚轮事件覆盖同类滚动路径，但不替代硬件手势实测。

最终检查：422 项集成测试通过（1 项原有跳过）、96 项桌面测试通过、7 项 JavaScript 测试通过。源码与最终打包页面各通过 23 组浏览器检查，75 个模板/静态资源一致。

原生实测通过普通快速拖动、双击最大化、最大化拖回、右边缘/右下角缩放、最小化、关闭取消、Alt+F4 和确认退出。正常原生还原的四条路径均通过子控件坐标检查。一次自动化工具唤回窗口出现子控件偏移，通过 Windows+Up 恢复；未独立复现原因，保留在验证记录中，不以此修改正常还原逻辑。
