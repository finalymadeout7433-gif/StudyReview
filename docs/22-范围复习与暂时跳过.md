# 范围复习与暂时跳过

更新4修复更新3中“从章节进入复习，保存后转到全局队列”的问题。课程、章/节、知识点和标题关键词形成同一个范围，贯穿题目列表、错题详情、作答、对照、自评、保存、跳过、返回列表和分页。页面始终显示本轮范围，只有主动点击“切换到全部课程”才扩大范围。

## 行为约定

- 父章包含直接子节；一个题目关联多个知识点或横跨多个章节时，在当前范围只出现一次。它在另一个关联章节中也可被找到，仍是同一个题目，不复制历史。
- 仅未归档课程中的未归档到期题参与复习。未来题、归档题不会被带入，范围无题时明确显示空状态。
- 保存后寻找当前范围下一道未跳过的到期题。最后一题按钮显示“保存并查看本轮结果”，不再进入其他章节。空状态不声称全局完成或全部掌握。
- “暂时跳过这题”为带CSRF保护的POST，仅记录当前浏览会话的轮次状态；不写复习记录、不修改下次日期、不推进FSRS，也不自动保存未提交答案。
- 跳过后继续本范围下一题；全部跳过或最后一题保存后仍有跳过题，显示“本轮已浏览，仍有N题待复习”，可重新查看。不能把跳过当作已完成。
- 回到已经跳过的题仍可正常作答保存；提交后从剩余范围继续。重复保存依然复用原业务提交标识，不重复产生复习记录。

## 数据边界

范围对象逐一验证所属用户及相互关系。课程/章节/知识点不一致、外部账号对象、范围外题目的提交在写入之前被拒绝，不能通过轮次参数扩大权限。每次请求重新读取实际到期状态，因此另一页面已完成的题会从队列自然消失。

跳过集合使用现有Django登录会话存储，轮次是随机标识并绑定用户和规范化范围。不同浏览器登录互相独立；服务重启后，只要原登录会话仍有效，范围与跳过集合可继续使用。退出登录清除该会话；最长24小时后明确提示跳过状态失效并恢复同范围到期题，不扩大到全局。

每个会话最多保留20个轮次，每轮最多暂时跳过2000题，以限制会话元数据大小；达到上限提示回到列表重新查看。没有新增表、迁移或认证设置，当前仍为22业务表、31总表、44外键、24触发器。

## 界面与验证

范围卡片使用现有绿色和暖白体系，提供清楚的范围名、待处理和跳过数量、范围内错题和全局切换入口。窄屏自动纵向排列，短题干取消强制留白，让作答区域更靠近题目。

用独立合成账号验证了父子章、多对多去重、跨章、课程/知识点/关键词、最后一题、空范围、跳过全部、跳过后保存、重复提交、无效答案、归档、CSRF、外部账号拒绝、轮次失效和浏览器返回。实际Edge流程包含跳过后重启服务、保存最后一题、重新查看跳过题、范围清空后主动切换全局；真实队友数据不写入测试内容。

这是本地学习流程改进，不是跨设备同步。新版生产账号完整包、第二台电脑恢复、物理休眠/断电仍未验证。
