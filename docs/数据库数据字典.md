# 数据库数据字典

由当前 Django 5.2.17 模型元数据生成；共 19 张业务表。生成过程不读取安全配置、不连接 MySQL，也不读取真实记录。

数据库另有 Django 账户、权限、会话和迁移系统表。完整 SQL、触发器及数据库课程说明见 [04-数据库课程说明.md](04-数据库课程说明.md)。迁移文件是结构演进的执行依据，结构 SQL 供课程阅读。
