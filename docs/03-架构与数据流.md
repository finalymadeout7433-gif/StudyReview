# 架构与数据流

同一 Django URL/认证/服务/MySQL，既可浏览器开发，也可 Windows 壳运行。界面为 Django 模板和离线 CSS/JavaScript，系统中文字体，无 React 双栈。

| 层 | 代码 | 职责 |
| --- | --- | --- |
| 模板/交互 | templates、static | 表单、导航、图片、错误、助手差异与刷新 |
| HTTP | 各 app urls/views/forms | 登录/CSRF、参数、当前用户读取与服务调用 |
| 业务 | learning、attachments、assistant、scheduling、ai_gateway/services | 归属、归档、版本、事务、幂等、算法和预算 |
| 存储 | ORM、mysqlclient、MySQL | FK/唯一/CHECK/索引/触发器和参数化查询 |
| 私有文件 | 数据目录 private | 图像/缩略图、签名、引用、DPAPI与窗口缓存 |
| 桌面 | desktop main/runtime/webview_window | Waitress、WhiteNoise、实例锁、WinForms/WebView2 |

## 启动

解析本人数据与配置引用 → 只读预检 → 必要时人工配置向导 → Django WSGI(DEBUG=False) → Waitress 随机 127.0.0.1 → 原生窗口。WhiteNoise仅服务已收集资源，不公开媒体；窗口限制本次源，停止入口校验本次身份再协作退出，不杀共享MySQL。

程序与私人数据分开。新bootstrap是显式一次性命令，仅新建不存在的库；正常启动不会建库/seed/迁移。

## 任务与错题

已登录视图 → 表单 → 服务按用户锁课程/子对象 → 归档和签名校验 → 事务保存。完成状态与完成时间一致，恢复清空时间；逾期是未完成且截止早于上海今天，不额外存状态。

错题编辑只能用同课程知识点和本人图片；当前图片关系可更新，历史快照不变。数据库用户与网站用户不同；子对象沿 Course.owner 决定归属，FK不能自动替代权限。

## 复习事务

先作答再看答案与自评 → 签名版本含算法revision → 锁课程、错题、State → 重算建议 → ReviewRecord文本/图片快照、ScheduleEvent、State、题目下一日期在同一根事务保存。第二步失败第一步也回滚；UUID/唯一/版本防双击与旧覆盖。

磁盘写入不是MySQL事务，图片服务另有清理/路径保护，不能声称数据库回滚磁盘。

## 助手

本地候选 → 明确选对象 → 主动限定上下文 → 持久预算预留/dispatched → 独立外部请求 → schema/范围验证 → Draft差异 → 单独人工确认事务 → 页面重读并恢复会话。模型不能选owner/执行SQL/确认；不确定外部结果保留账本，不自动重试。

## 统计

当前用户和归档范围限定列表；上海日期区间转 UTC 半开区间，ORM条件聚合。完成率分母零显示无任务；复习数是记录数，同题重复计；自评分布不是正确率。详见下列子模块与数据库文档。
