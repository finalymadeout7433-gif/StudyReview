# 工具、依赖与版权

## 工具

运行必需：Windows x64、MySQL8.4、WebView2、兼容.NET/VC++；首次下载入口在01。DBeaver可选，用于看表/关系，不是网站后端。源码开发用CPython3.13、venv/pip、Git；GitHubCLI可选用于本人账号/仓库/Release；编辑器可用VSCode；PyInstaller只构建。软件ZIP不需要另装Python/Git。

本轮复用现有工具，没有安装未知skill或操作AIC/GPU；新电脑从官方渠道补齐组件，软件不安装/启停共享数据库。

## Python实现分工

| 组件 | 作用 |
| --- | --- |
| Django5.2.17、asgiref/sqlparse/tzdata | 认证、ORM、表单、模板、迁移、框架和时区 |
| mysqlclient2.3.0 | 参数化MySQL驱动 |
| Pillow12.3.0 | 验证/去元数据/规范化/缩略图 |
| fsrs6.3.2、typing_extensions | 确定性算法，无optimizer/Torch |
| Waitress3.0.2 | 壳拥有的本机WSGI服务 |
| WhiteNoise6.12.0 | collectstatic后资源，不公开media |
| pywebview6.2.1 | WebView2/WinForms |
| pythonnet3.2.0、clr_loader | Python/.NET桥 |
| cffi/pycparser/bottle/proxy_tools | 桌面底层依赖 |
| PyInstaller6.22.3与hooks/altgraph/pefile等 | onedir冻结，仅构建 |

精确版本锁在requirements三个文件，元数据和许可见materials/desktop-dependency-manifest.json。无React/OCR引擎/本地LLM权重/CUDA。
