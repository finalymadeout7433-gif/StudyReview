# 界面整理与学习统计图表

本文记录第一轮布局与六类图表；后续扩展见 [15 课程示例与记忆分析](15-learning-examples-and-memory.md)。

本分支增加统一的学习空间布局：暖白底色、墨色文字、绿色主要操作和少量品牌红。使用现有 Django 模板与离线 CSS/JavaScript，不需要 Node 构建、外部字体或在线图表服务。

## 页面变化

- 登录与注册：介绍区和表单区分栏，小窗口改为纵向；保留字段错误、CSRF、登录跳转和密码显示切换。
- 学习空间：固定宽度导航、统一标题/表单/卡片/表格密度；主内容不再被侧栏和助手挤成窄列。
- 任务：日期、状态保持横排；常用“完成/恢复、编辑”直接可见，AI 编辑、整理笔记和删除放入“更多”。窄屏任务改成卡片。
- 学习助手：默认回答学习问题；整理任务、错题和历史上下文放入可展开选项。从任务/错题进入会自动展开对应对象。未连接 AI 时按钮明确写“保存问题到本机”。密钥、预算和外发确认保留。
- 统计：六类图表、课程筛选、自定义日期和近7天/30天/12周快捷区间；课程和知识点条形图可进入相应清单。

## 图表的数据口径

| 图表 | 数据来源与范围 |
| --- | --- |
| 复习趋势 | 当前用户活跃课程中的未归档错题，所选日期的复习记录；长区间合并为最多30个桶 |
| 复习自评分布 | 同一复习记录集合的 again/hard/good，不代表答题正确率 |
| 任务完成对比 | 当前活跃课程的任务，区分完成、未逾期、逾期；按任务总数展示前8门 |
| 知识点分布 | 当前未归档错题与知识点的关联，最多8项；一题可计入多个知识点 |
| 未来7天安排 | 今天至第6天的当前下次复习日期；过期题单独提示，不计入未来柱形 |
| 复习活动日历 | 所选区间最后最多84天的逐日复习次数；色深按本次区间内的最大值分级 |

日期边界按 Asia/Shanghai 的自然日处理；数据库使用半开时间区间。图表逐日分组在 Python 中转换时区，不要求 MySQL 安装时区表。读取不修改原记录，也不新增数据库表或迁移。

空数据展示零值或提示；不填造学习时长、正确率和连续学习天数。课程/知识点名称通过 Django json_script 和 DOM textContent 输出。趋势保留可展开的数据表，课程明细表保留。

## 后续修改位置

| 文件 | 用途 |
| --- | --- |
| `static/css/studio.css` | 基础统一布局和响应式样式 |
| `static/css/readability.css` | 阅读层次调整：正文15px、表格14px、说明13px、图表标签12px；最后加载以统一字号和对比度 |
| `templates/base.html` | 导航、顶栏、公共资源 |
| `templates/registration/login.html` / `register.html` | 登录、注册布局 |
| `templates/learning/task_list.html` | 任务表格、更多菜单 |
| `templates/learning/statistics.html` | 统计筛选、六类图表容器和明细 |
| `learning/analytics.py` | 图表数据聚合；用户、课程、归档及时间范围 |
| `static/js/charts.js` | 本地 SVG 图表和日历；窗口宽度改变时重绘 |
| `templates/partials/assistant_panel.html` / `static/js/assistant.js` | 助手布局、展开逻辑、状态和会话操作 |
| `static/js/studio.js` | 密码显示切换与任务菜单的小交互 |
| `learning/tests/test_analytics.py` | 隔离、归档、时间边界、重复计数、空数据、长区间和安全输出测试 |

预览启动前需要 collectstatic；本分支的开发启动脚本已包含该步骤。不要以旧版本 EXE 的界面判断源码是否生效。分发桌面版仍需另行打包、验收。
