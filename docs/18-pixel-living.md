# 像素生活版

版本：2.2.0-defense.20261108.pixel3

## 本轮变化

- 保留原有专注小屋，增加原创像素学习者。开始新一轮时从右侧走到书桌，坐下后交替阅读和写字；暂停或结束后喝水、伸展和走动。状态只读，不影响计时或保存逻辑。
- 七个主要模块分别使用晨光草甸、林间书径、果园菜畦、暮色山径、温故海岸、星河山谷和林中档案场景。页面、侧栏和卡片采用各自对应的柔和色板。
- 侧栏改为纵向森林溪流画面，填充较高窗口的闲置空间；缩小外部边距，宽屏内容最大宽度由 1600px 扩为 1920px。小屏保留紧凑导航和可操作按钮。
- 海岸灯塔点亮时显示明显光束与亮色灯芯，熄灭后光束消失且灯芯变暗；专注小屋窗外灯塔同样加强区别。
- 导航保留普通服务器页面和历史行为，不拦截点击。旧版最多 12 个截图层、裁剪和交错动画改为一次 120ms 的透明度/4px 位移动画；去掉图表额外 350ms 淡入。点击立即提供侧栏反馈。
- 全局装饰动态开关、系统减少动态、离屏及隐藏窗口暂停均保留。专注暂停期间角色的休息动作与计时分离。所有素材为本地原创 SVG，无额外网络或依赖。

## 性能验证

在相同最终界面和合成数据下，仅替换新旧导航资源做受控 A/B，各 18 次侧栏切换（本机无界面 Edge）：

- 点击到加载完成中位数 / P95：100.5 / 121 ms → 89 / 108 ms。
- 首次内容绘制中位数 / P95：84 / 152 ms → 68 / 116 ms。
- 服务器首字节中位数约 22 ms，基本不变。
- 两组均未观察到超过 50ms 的主线程长任务。
- 超过 34ms 的帧间隔：1 / 1755 → 0 / 1765。

这是小样本本机测试，不代表所有电脑和数据规模的保证。路由替换测试会关闭浏览器普通 HTTP 缓存，绝对数值不应直接当作日常启动耗时。优化针对渲染和动画开销，不宣称数据库速度提升。
