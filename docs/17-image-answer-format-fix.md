# 普通图片答疑格式修复（2026-10-28）

现场表现：文字首问成功，图片分析和后续提问显示通用“处理失败”。只读诊断确认本机PNG校验通过，官方API返回HTTP成功、可靠用量和stop结束标记；模型content未通过严格JSON解析（错误位置在字符串末尾）。输出token未达到上限，不能归因为图片尺寸或回复长度超限。

根因是所有答疑都被要求返回任务修改用的text/drafts结构。普通答疑本身只需要可显示的文字，不应依赖该结构完整性。

修复：Gateway对未选定课程或修改对象的普通答疑使用text响应格式和普通答疑指令；回答仅显示，不生成草稿。显式选定内容的修改继续使用严格JSON解析、字段校验与确认流程。普通模式也拒绝空回复、截断或工具调用；不提取不完整JSON字段、不执行模型输出、不自动重试。兼容有效且没有草稿的旧回答封装。

沿用官方固定端点、账户密钥、预算预留、用量结算与请求去重。未重新配置密钥、未重置账本、未增加预算。修复后通过正常服务复用原有图片与提问做一次幂等验证，获得1099字符的真实图片分析并保存为普通聊天记录，账本成功，未生成修改草稿。旧失败记录保留。

回归覆盖文字/图片普通答疑、明确内容整理仍走结构化模式、普通模式不能生成数据库修改、空回复与截断拒绝，以及预算和幂等流程。开发预览重启加载修复，未打包旧EXE、未上传GitHub。
