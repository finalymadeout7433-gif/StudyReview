# 像素学习版：前端优化与验收

版本：2.2.0-defense.20261108.pixel1
日期：2026-11-08

## 设计与范围

保留原有奶油色、鼠尾草绿、陶土红以及可读字体，不套用参考图的紫蓝配色。
参考图采用的导航图标、模块层级和卡片差异被转化为克制的本地像素细节。
全部图形为原创内联 SVG，没有复制 Minecraft 的素材，也没有新增在线资源或第三方依赖。

- 八个导航图标、页面标题图标、概览指标图标、课程卡片图标和轻量格纹。
- 专注页新增学习小屋：书桌、书架、窗景、台灯、植物、书本、茶杯和小猫。
- 只有正在专注时，云、蒸汽、书页与叶片缓慢变化。
- 暂停专注、页面隐藏、场景离开可视区域时停止画面。
- “画面动态”独立控制装饰，不修改计时、保存或专注状态。偏好按本机账号保存。
- 跟随系统“减少动态效果”；无 JavaScript 时仍保留静态场景与原有表单。
- 小屏准备界面使用缩略场景，保留开始、暂停和保存入口的首屏可达性。

计时、复习算法、数据库模型和迁移、用户数据、助手逻辑均未修改。
软件版本标识已更新，方便区分旧版；没有推送或发布到 GitHub。
