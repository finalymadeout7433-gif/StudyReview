## 已有安装升级

先退出旧窗口，备份原数据库和完整学习数据目录private/。保留旧程序作为回退版本。不要对已有库执行“首次初始化”。先按docs/02-开发环境与协作.md准备新版源码环境，再在本人原数据目录的private/schema-plan.json写入：

```json
{"purpose":"study-review-v2-upgrade","database":"study_review_dev"}
```

仅对标准正式库study_review_dev使用下面的升级命令；自定义开发库沿用其已有开发迁移配置。PowerShell中把路径替换为本人实际位置：

```powershell
$env:STUDY_DATA_DIR='D:\MyStudyData'
$env:STUDY_CREDENTIALS_FILE='D:\MyStudyData\private\database-credentials.json'
$env:STUDY_ALLOW_SCHEMA_ADMIN='1'
python manage.py migrate --settings=config.v2_migration_settings
Remove-Item Env:STUDY_ALLOW_SCHEMA_ADMIN
```

确认迁移成功，再解压新版运行包，从“环境检查与配置”选回原数据目录/配置文件，随后启动。新增字段标记初始化练习来源；已有复习默认为本人记录，不重放、不删除历史。若迁移失败，保留原数据及备份排查，不删库。

## 新电脑与内容

新安装按首次启动说明创建自己的全新数据库。初始化可选择公开演示数据；七门课的内容模板位于learning/example_curriculum.py，独立开发环境可按docs/15-learning-examples-and-memory.md导入。新注册账户不会自动获得其他人的课程或聊天，日常可从界面自行添加。
