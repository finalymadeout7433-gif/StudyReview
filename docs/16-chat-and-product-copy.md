# 聊天界面与产品文案（2026-10-28）

本轮清理任务、错题名称的导入前缀，缩短登录、概览、课程、任务、错题、复习与统计页文案。图表模型和数据来源说明保留在折叠区域。初始化复习的 is_example 标记不变，统计以“练习记录”和“我的复习”区分。

学习助手使用独立对话窗口。左侧历史，右侧消息与输入；设置和任务/错题整理放入次级入口。支持安全的基本 Markdown、代码块、复制、自动命名、会话草稿隔离、最近12条连续上下文、图片选择/拖放/粘贴、Enter发送及Shift+Enter换行。任务和错题的修改继续先预览再确认。

截图通过用户主动点击 getDisplayMedia 选择画面，读取一帧即释放采集轨道；本地框选确认后加入附件。选择超时、取消、失败和迟到结果均释放采集资源。运行环境不支持时，使用Windows截图与Ctrl+V。没有桌面录屏服务、原生权限桥或自动截图上传。

DeepSeek沿用现有官方端点与deepseek-flash图像请求适配器。未配置或额度不足时保留输入，打开设置，不生成伪回复、不创建空消息。保存设置表示配置完成，界面不声称已经在线验证。本轮未填写密钥、未发送真实请求。

本轮验收：Django 315项（314通过、1跳过）；桌面79项通过；前端7项通过。覆盖自动会话命名、幂等重放、历史安全显示、截图裁剪/比例/轨道释放/超时迟到、安全文字渲染。已在浏览器检查桌面和390px宽度、图片上传与Ctrl+V粘贴、未连接保留输入、新建空对话不落库。未在所有浏览器和独立WebView中验证系统截图选择器；后续接入真实密钥后还需真实文字与图片答疑联调。

本轮不打包EXE、不提交或推送Git。代码运行于独立开发预览8001和开发数据库3308。
