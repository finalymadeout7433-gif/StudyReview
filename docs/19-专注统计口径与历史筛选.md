# 专注统计口径与历史筛选

今日和近7日使用同一个有效区间计算器。近7日指北京时间今天及前6天；统计全部课程并包含正在进行的有效区间，每15秒同步。暂停和休息不计入，单轮最多累计目标时长，跨午夜按区间与每天的交集拆分。

每天显示到秒；汇总先保留原始区间的微秒精度，再转换成分钟。例如23:50:00.500开始的一轮25分钟，午夜两侧分别为599.5秒和900.5秒；逐天先取整会只剩1499秒，误显示24分钟，因此合计使用原始精度计算，正确为25分钟。每天显示值与合计的独立取整已在页面说明。

历史筛选与按天统计是两种不同问题：

- 历史按**轮次开始日期**筛选，包含首尾日期，展示整轮有效时长；每页12条，可查全部历史。
- 按课程（含已归档课程）、自由专注筛选；课程只来自当前账号。分页保留条件，重置操作明确。
- 无效或反向日期显示错误并返回空列表，不会无声扩大范围。
- 今日与近7日不受历史筛选影响，导出也仍是全部当前账号专注记录；页面均已明确标注。
- 删除任务会清空可空任务外键，但历史标题与专注区间保留，所以时长不会消失。归档课程仍可查看历史。没有增加删除专注事实的界面。
- 没有记录时显示零值与引导；无虚构曲线、目标进度或补填记录。不到1秒的区间仍算有投入的一天，显示到秒时允许为0。

计算器按时间范围选择有关轮次并预取区间，七日统计固定使用2次ORM查询，而不是逐天重复查询；这是查询数量验证，不是大规模性能压测。

本轮无模型修改和新迁移。新版代码在只读事务中分别读取当前答辩库与已恢复的验证库，历史查询、统计与页面均成功，结果一致。当前真实账号专注记录为0；有数据的筛选与统计使用合成账号验证，未污染真实账号。

备份仍以完整SQL＋媒体为准；专注JSON只是单项导出，不包含完整账户，也没有新增覆盖式导入。跨机完整账号包、物理休眠、断电、长时间后台和大规模压力测试仍未验证。
